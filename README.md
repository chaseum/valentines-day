# Valentine Quiz (NES.css)

A minimalist, single-page Valentine's Day quiz built with vanilla HTML, CSS, and JavaScript using NES.css styling.

## Run

- Open `index.html` in your browser, or
- Serve locally:

```powershell
cd (whatever folder)
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

- Update questions and answers in `app.js` under the `QUESTIONS` array.
